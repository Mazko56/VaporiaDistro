VAPORIA DISTRO — Telegram Mini App + Bot + PostgreSQL (Railway)
=============================================================

1. Повне ТЗ: docs/TZ.md
2. Інструкція Railway + GitHub Windows: docs/RAILWAY.md
3. Що входить та що не входить: README.md
4. Юридичні вимоги 18+: docs/LEGAL_LAUNCH.md
5. Бекапи: docs/BACKUP.md

Технології: TypeScript, React + Vite, Node.js/Express, grammY, PostgreSQL.

Швидка схема: розпакувати в C:\vaporia-distro → GitHub →
Railway New Project (репозиторій + PostgreSQL) → Railway Variables → Redeploy.

Код і таблиці — у папках server та src. Демо-дані створюються лише якщо
SEED_DEMO_DATA=true. Ціни, залишки і контент демо необхідно замінити.

УВАГА: ENABLE_CHECKOUT=false за замовчуванням у production. Перед запуском
продажів потрібно налаштувати законний контроль віку та перевірити чинні
правила для товарів із віковими обмеженнями. Самодекларація 18+ не достатня.

Секретні ключі/токени не включені. Вводьте їх ТІЛЬКИ в Railway Variables.
